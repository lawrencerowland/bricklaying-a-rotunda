What you’re seeing

The inner ring is the first course; later courses are drawn farther out so you can compare them. This is a radial diagram, not a widening wall. Lines connect consecutive placements, not the builder’s travel route. The green dot marks the first brick; amber arrows show the direction on sampled courses.

Clockwise, anticlockwise and alternating use one fixed brick layout. Staggered also shifts every second course by half a brick, so it compares a different layout—not merely another order on identical positions.

This is a spatial-order comparison, not a complete project-state model. It does not model curing, shared resources, structural support, time or reachable completion schedules. Settings and selections are temporary; reloading restores the defaults. No project record or file is saved.
